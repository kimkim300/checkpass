# 결석계 관리 웹앱

학교 서류(결석신고서, 교외체험학습 신청서·보고서) PDF를 등록해두면, 학부모가 웹에서 바로 내용을 입력하고
서명해서 제출하고, 담임 교사는 대시보드에서 제출 현황을 확인한 뒤 기간별로 PDF를 합쳐 교무실에 제출할 수 있는 앱입니다.

## 구성

- 순수 HTML/CSS/JS (빌드 도구 없음), Firebase(인증/데이터베이스/파일저장)를 사용합니다.
- 결석계 PDF에 학부모 입력값과 서명을 직접 그려 넣기 때문에 서버 프로그램이 따로 필요 없습니다.
- 학부모가 제출한 서명·PDF·첨부사진 등 민감한 개인정보는 "서류 수합" 화면에서 교무실 제출 후 버튼 한 번으로 삭제할 수 있습니다(대시보드 통계 기록은 유지).

## 1. Firebase 프로젝트 준비 (최초 1회, 약 10분)

1. https://console.firebase.google.com 에서 새 프로젝트를 만듭니다. (무료 Spark 요금제로 충분)
2. 왼쪽 메뉴 **Build > Authentication** → "시작하기" → 로그인 방법에서 **이메일/비밀번호**를 사용 설정합니다. (화면에는 "관리자 번호"만 보이지만, 내부적으로는 이 방식을 이용해 번호별 계정을 자동으로 만듭니다.)
3. **Build > Firestore Database** → 데이터베이스 만들기 → (테스트 모드가 아닌) **프로덕션 모드**로 시작 → 위치는 asia-northeast3(서울) 권장.
4. **Build > Storage** → 시작하기 → 프로덕션 모드로 시작.
5. 왼쪽 위 톱니바퀴 → **프로젝트 설정** → 아래로 스크롤 → "내 앱"에서 웹 앱(</> 아이콘) 추가 → 앱 닉네임 아무거나 입력 → Firebase Hosting 설정은 건너뛰어도 됩니다.
6. 화면에 나오는 `firebaseConfig` 객체 값을 복사합니다.

## 2. 설정 파일에 값 붙여넣기

`public/js/firebase-config.js` 파일을 열어 위에서 복사한 값으로 교체합니다.

```js
export const firebaseConfig = {
  apiKey: "...",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "...",
};
```

## 3. 배포 (Firebase Hosting)

Node.js가 설치되어 있어야 합니다.

```bash
npm install -g firebase-tools
firebase login
firebase deploy
```

배포가 끝나면 `https://<프로젝트ID>.web.app` 주소가 나옵니다. 이 주소로 어디서든(학부모 스마트폰 포함) 접속할 수 있습니다.

> `firebase deploy` 시 `firestore.rules`, `storage.rules`도 함께 적용됩니다. 두 파일은 "본인 학급 데이터는 본인만 관리, 학부모는 로그인 없이 제출만 가능"하도록 이미 작성되어 있어 별도 설정이 필요 없습니다.

### 배포 전에 로컬에서 미리 보기

```bash
firebase emulators:start --only hosting
```
또는 간단히 `npx serve public` 실행 후 브라우저로 열어도 됩니다. (파일을 더블클릭해서 여는 `file://` 방식은 동작하지 않습니다.)

## 4. 사용 순서

**교사**
1. 배포된 주소 접속 → 홈 화면에서 "선생님이신가요?" 클릭 → "관리자 번호" 입력 후 입장 (처음 입력하는 번호면 자동으로 등록되고, 이후에는 같은 번호로 계속 접속합니다. 번호는 꼭 기억해두세요 — 잊어버리면 복구할 수 없습니다.)
2. "학급 만들기" → 학급 이름/학년반 입력
3. **학생 명단** 메뉴에서 학생 등록 (일괄 등록 가능)
4. **서류 양식** 메뉴 상단에서 결석계 / 교외체험학습 신청서 / 교외체험학습 보고서 중 등록할 종류를 선택 → 해당 PDF 업로드 → 왼쪽 목록의 입력 항목을 순서대로 클릭 후 PDF 위 원하는 위치를 클릭해 배치 → "샘플 값으로 미리보기"로 확인 → "양식 저장" (세 가지 서류를 각각 따로 등록해야 합니다. 필요 없는 서류는 등록하지 않아도 됩니다.)
   - 잘못 올렸거나 서식이 바뀌면 "이 양식 삭제" 버튼으로 삭제 후 다시 등록할 수 있습니다.
5. **대시보드**의 제출 링크를 복사해 학급 학부모들에게 공유 (문자/카카오톡 등) — 링크 하나로 세 가지 서류를 모두 제출할 수 있습니다(제출 화면에서 서류 종류를 선택).
6. 학부모가 제출하면 대시보드에서 날짜별/학생별로 확인, 필요 시 반려
7. **서류 수합** 메뉴에서 서류 종류와 기간을 선택해 PDF를 하나로 합쳐 다운로드 → 교무실 제출 → "파일 정리" 버튼으로 원본 삭제

**학부모**
1. 교사가 보낸 링크 접속 (회원가입 불필요)
2. 제출할 서류 종류 선택 → 자녀 이름 선택 → 내용 입력 → 서명 → 제출

## 보안 관련 참고사항

- 학부모 제출 링크에는 학급을 식별하는 임의의 긴 ID가 포함되어 있습니다. 이 링크는 **해당 학급 학부모에게만** 공유하세요(공개 게시판 등에 올리지 마세요).
- 결석 기록(학생 이름, 사유, 서명, 첨부사진)은 담임 교사 본인만 열람할 수 있습니다.
- "서류 수합" 후 "파일 정리"를 누르면 서명·PDF·사진 원본이 서버에서 즉시 삭제되어 장기 보관되지 않습니다.

## 파일 구조

```
firebase.json / firestore.rules / storage.rules   Firebase 설정 및 보안 규칙
public/
  index.html      홈 화면 (교사/학부모 안내)
  teacher.html    교사 로그인(관리자 번호) · 학급 선택
  roster.html     학생 명단 관리
  template.html   서류 양식 등록 (결석계/체험학습 신청서·보고서, 입력란 위치 지정)
  submit.html     학부모 제출 페이지 (공개 링크, 서류 종류 선택)
  dashboard.html  교사 대시보드 (날짜별/학생별/미제출자)
  export.html     기간별 PDF 수합 및 정리
  js/             각 화면 로직 + 공통 유틸(pdf-fill.js, signature-pad.js 등)
  assets/fonts/   PDF에 한글을 그려 넣기 위한 폰트 (Noto Sans KR)
```
